# GhumneChalo --- UI Reference Specification

## Source

A supplied UI reference image is part of the project input.

The image presents: - GhumneChalo branding - mountain/travel imagery -
green, blue and orange/yellow palette - desktop sidebar - mobile app
shell - destination search - AI trip planner - itineraries - budget
manager - weather - smart routes - packing assistant - emergency mode -
achievements

## Visual Language

### Primary

Green: - nature - travel - primary actions

### Secondary

Blue: - technology - trust - informational modules

### Accent

Orange/yellow: - adventure - exploration - highlights - warnings where
appropriate

### Neutral

White/light backgrounds: - clean - simple - readable

## Components

Use: - rounded cards - soft shadows where useful - strong headings -
readable body text - clear CTA buttons - icon-led feature cards -
destination imagery - responsive grids - sidebar on desktop -
bottom/mobile navigation on mobile

## Important

The image is a product/design reference, not a literal technical
specification.

Implement a coherent responsive UI inspired by the reference while
making real features functional.

Do not leave buttons as decorative placeholders.
