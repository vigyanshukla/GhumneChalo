# GhumneChalo --- Packing, Emergency & Achievements

## Packing Assistant

Inputs: - destination - dates - duration - weather - interests - trip
type

Generate categories: - clothing - documents - electronics -
health/essentials - activity-specific items

User can: - check/uncheck - add custom item - delete - save -
print/download

## Emergency Mode

Provide: - current location permission - nearby emergency-relevant
places - police - hospitals - pharmacies - useful emergency information

Never invent phone numbers, addresses or availability.

If live data is unavailable, clearly say so and provide only
verified/static information configured by the product.

Emergency UI must be visually obvious and fast to access.

## Achievements

Examples: - First Trip - Travel Explorer - Foodie Explorer - Nature
Lover - Multi-Trip Planner - Budget Master

Achievement events should be derived from actual user actions.

Do not award achievements from fake/demo actions.

## Progress

Show: - earned - locked - progress - date earned
